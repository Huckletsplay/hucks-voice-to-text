# Security Policy

## Supported versions

Security fixes are applied to the latest public beta available through GitHub Releases.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a
public issue containing exploit details, dictated text, recordings, credentials, or personal file
paths.

Include the macOS version, app version, reproduction steps, and expected impact. You should receive
an acknowledgment within seven days.

## Privacy boundary

Huck's Voice to Text is designed to keep speech and text on the Mac. Recognition runs locally, and
the app contacts GitHub only when the user explicitly chooses **Check for Updates**. Reports of an
unexpected network request, dictated text reaching the wrong application or field, text written
into a password field, or recovery drafts stored anywhere unexpected are especially important.
